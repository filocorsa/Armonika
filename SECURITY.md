# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately through GitHub instead: on the repository page open **Security**, then **Report a vulnerability**. Include what you found, how to reproduce it and the version or commit you tested.

You will get an answer within a week. Once a fix is ready, it is released first and the report is published after.

## Supported versions

Armonika is in early development and has no stable release yet. Only the latest commit on `main` receives security fixes.

## Scope

Armonika is a server you expose on your network, so reports about authentication, access to libraries a user was not granted, path traversal outside a library and anything reachable without logging in are especially welcome.
