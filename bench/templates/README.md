# Silent audio templates

These seven files are the templates that the test data generator copies and then
writes tags into. They are generated by ffmpeg 6.1.1 from `anullsrc` (digital
silence), so they contain no recording and no third-party rights. Each lasts
0.2 seconds (44100 Hz stereo; Opus uses 48000 Hz) and carries no metadata
tags, except the encoder name that libvorbis and libopus always write into
Ogg streams (`encoder=Lavc libvorbis`, `encoder=Lavc libopus`).

Commands, run from this directory (`bench/templates/`):

```sh
ffmpeg -y -f lavfi -i anullsrc=r=44100:cl=stereo -t 0.2 -map_metadata -1 -fflags +bitexact -flags:a +bitexact -c:a libmp3lame -b:a 64k -write_xing 0 -id3v2_version 0 silence.mp3
ffmpeg -y -f lavfi -i anullsrc=r=44100:cl=stereo -t 0.2 -map_metadata -1 -fflags +bitexact -flags:a +bitexact -c:a flac silence.flac
ffmpeg -y -f lavfi -i anullsrc=r=44100:cl=stereo -t 0.2 -map_metadata -1 -fflags +bitexact -flags:a +bitexact -c:a libvorbis -q:a 0 silence.ogg
ffmpeg -y -f lavfi -i anullsrc=r=48000:cl=stereo -t 0.2 -map_metadata -1 -fflags +bitexact -flags:a +bitexact -c:a libopus -b:a 32k silence.opus
ffmpeg -y -f lavfi -i anullsrc=r=44100:cl=stereo -t 0.2 -map_metadata -1 -fflags +bitexact -flags:a +bitexact -c:a aac -b:a 64k silence.m4a
ffmpeg -y -f lavfi -i anullsrc=r=44100:cl=stereo -t 0.2 -map_metadata -1 -fflags +bitexact -flags:a +bitexact -c:a pcm_s16le silence.wav
ffmpeg -y -f lavfi -i anullsrc=r=44100:cl=stereo -t 0.2 -map_metadata -1 -fflags +bitexact -flags:a +bitexact -c:a pcm_s16be silence.aiff
```

The M4A file is AAC-LC; the OGG file is Vorbis.

`cover.jpg` is an 8x8 black JPEG that the test fixtures embed as a cover:

```sh
ffmpeg -y -f lavfi -i color=c=black:s=8x8 -frames:v 1 -map_metadata -1 -fflags +bitexact -flags +bitexact cover.jpg
```
